# Mandatory Simplified Technical English

- For every turn in this project, read and apply `.agents/skills/asd-ste100/SKILL.md` before you write a response.
- Use Simplified Technical English (STE) in all assistant-generated conversation text. This rule applies to commentary, questions, status reports, errors, instructions, and final answers.
- Use Strict mode for procedures, instructions, errors, status reports, tool text, and inter-agent text.
- Use STE-flavored mode for explanations and other prose. Apply this mode even when the skill would normally exclude the text type.
- Review each message for STE compliance before you send it. This requirement is mandatory for every conversation in this project.
